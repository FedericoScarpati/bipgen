    API reference¶

    Specification¶

    bipgen.spec.Spec dataclass ¶

    Validated specification. Sections are plain dictionaries mirroring the YAML.

    to_dict() ¶

    Plain dictionary in the YAML layout (arrays are referenced, not embedded).

    save(path) ¶

    Write the YAML file and, if arrays are present, the .npz next to it.

    bipgen.spec.load_spec(path) ¶

    Read a specification from a YAML file.

    bipgen.spec.spec_from_dict(data, base_dir=None) ¶

    Build and validate a :class:Spec from a dictionary in the YAML layout.

    arrays is the name of a .npz file, relative to base_dir, or a dictionary of arrays.

    bipgen.spec.SpecError ¶

    Bases: ValueError

    Raised when a specification is incomplete or inconsistent.

    Generation¶

    bipgen.generate.generate(spec, seed=None) ¶

    Draw one graph from spec.

    seed overrides the seed of the specification (default 42); the seed actually used is stored in graph.seed and graph.info["seed"]. The seconds spent in each step, and in total, are in graph.info["timing"].

    bipgen.graph.BipartiteGraph dataclass ¶

    A bipartite graph between side A (BCN, rows) and side B (TGT, columns).

    geometric and background are disjoint (n_bcn, n_tgt) sparse matrices of 0/1 entries; their sum is the full biadjacency matrix. The data array of these matrices is the slot for edge weights in later versions. info records how the realization was produced: the seed, the target and expected numbers of edges, solver diagnostics, and the seconds spent in each step (timing). target_degrees holds the (bcn, tgt) target degrees of the kernel model, and is None for the kNN model.

    biadjacency property ¶

    All edges, (n_bcn, n_tgt).

    degrees() ¶

    Realized degrees (bcn, tgt) counting all edges.

    edge_lengths() ¶

    Euclidean length of every edge, with its origin.

    edges() ¶

    Edge table with columns bcn, tgt and origin.

    Observed graphs¶

    bipgen.fit.spec_from_graph(biadjacency, *, scale, positions=None, background=None, n_bins=20, n_lags=2, sweeps=400, seed=42) ¶

    Kernel-model specification with the sizes and degrees of an observed graph.

    Parameters:

    Name Type Description Default
    biadjacency

    (n_bcn, n_tgt) sparse matrix; weights are ignored and isolated nodes are dropped.

    		 required
    scale float

    Kernel length, in units of the domain radius. Not fitted: choose it.

    		 required
    positions

    Optional (m, 2) array of known positions of some nodes (rows with NaN are ignored). When given, positions are drawn with the Metropolis method, with the cell occupancies (n_bins cells per axis) and the correlogram (lags 1 to n_lags, corrected for counting noise) measured on these points; otherwise uniformly.

    		 None
    background dict | None

    Background section of the specification; default no background.

    		 None

    bipgen.compare.statistics(obj) ¶

    Summary statistics of a graph or a biadjacency matrix.

    bipgen.compare.compare(real, ensemble) ¶

    Observed statistics against the ensemble.

    real is a :class:BipartiteGraph, a biadjacency matrix, or a dictionary with keys statistics (and optionally degrees), as returned by :func:bipgen.presets.observed.

    bipgen.compare.degree_ks(real, ensemble) ¶

    Kolmogorov-Smirnov distance of the degree distributions, per side.

    to_observed is the distance between the observed degrees and those of each realization; between_realizations the distance between consecutive realizations, which sets the scale of distances due to sampling alone.

    Saving and loading¶

    bipgen.io.save(graph, path) ¶

    Write graph to the directory path (created if needed).

    bipgen.io.load(path) ¶

    Read a graph written by :func:save.

    bipgen.io.read_edge_list(path, bcn='bcn', tgt='tgt', shape=None) ¶

    Biadjacency matrix from a CSV edge list with integer columns bcn and tgt.

    Repeated pairs are merged; the result is binary.

    Descriptors¶

    bipgen.descriptors ¶

    Registry of node and edge descriptors.

    A node descriptor maps a graph to one array per side; an edge descriptor maps it to one value per edge, in the row order of :meth:BipartiteGraph.edges. New descriptors are added with :func:register_node or :func:register_edge.

    register_node(name) ¶

    Decorator for func(graph) -> (array_bcn, array_tgt).

    register_edge(name) ¶

    Decorator for func(graph, edges) -> array with one value per row of edges.

    available() ¶

    Names of the registered descriptors.

    node_descriptors(graph, names=('degree',)) ¶

    One table per side ("bcn", "tgt"), one column per descriptor.

    edge_descriptors(graph, names=('degree_sum',)) ¶

    The edge table of graph with one extra column per descriptor.

    Presets¶

    bipgen.presets ¶

    Specifications shipped with the package, built from published datasets.

    Each preset is a YAML specification with a companion .npz of arrays and a JSON summary of the observed graph it was built from. See presets/README.md for sources and choices.

    available() ¶

    Names of the shipped presets.

    load(name) ¶

    The specification of preset name.

    observed(name) ¶

    Summary of the observed graph behind preset name, for :func:bipgen.compare.compare.

    Figures¶

    bipgen.plot.plot_graph(graph, ax=None, max_edges=3000, node_size=3.0, seed=0) ¶

    Nodes of both sides and a random subset of edges (2D or 3D).

    Geometric and background edges are subsampled in the same proportion, so the picture keeps their relative abundance. max_edges=0 hides edges.

    bipgen.plot.plot_degrees(graph, axes=None) ¶

    Complementary cumulative degree distributions, realized and target, on log-log axes.

    bipgen.plot.plot_edge_lengths(graph, ax=None, bins=60) ¶

    Distribution of edge lengths, geometric and background edges separately.

    bipgen.plot.plot_comparison(table, ax=None) ¶

    z-score of each observed statistic within the ensemble; the band marks |z| <= 2.

    Statistics with no spread in the ensemble have no z-score: they are drawn as hollow markers at 0 and labelled "no spread".
